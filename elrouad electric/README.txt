مشروع موقع الرواد اليكتريك
==========================

محتويات المشروع:
- index.html : الصفحة الرئيسية للموقع.
- assets/logo.jpg : شعار الشركة.
- assets/workshop-operator.jpg : صورة الفني أثناء العمل.
- assets/electrical-panel.jpg : صورة اللوحة الكهربائية.

طريقة الرفع على Cloudflare Pages (رفع مباشر):
1) فك ضغط ملف ZIP على جهازك.
2) افتح لوحة Cloudflare ثم Workers & Pages ثم Create application ثم Pages.
3) اختر Upload assets / Direct Upload.
4) ارفع مجلد المشروع أو ملف ZIP بعد فك ضغطه بحسب الخيار الظاهر.
5) تأكد أن index.html موجود في جذر المشروع (وليس داخل مجلد فرعي).
6) اضغط Deploy وانتظر نشر الموقع.

ملاحظات:
- الصفحة متوافقة مع الهاتف والكمبيوتر.
- روابط الاتصال والبريد وواتساب مضافة.
- الخطوط الخارجية تحتاج اتصال إنترنت، وتظهر خطوط بديلة إذا لم تتوفر.
- عدّل النصوص أو الصور داخل index.html ومجلد assets عند الحاجة.
